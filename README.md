# Endorphind

Endorphind is a pioneering creative and wellness company at the intersection of art, storytelling, artificial intelligence, and technology. We build AI applications and intelligent digital experiences, blending human artistry with cutting-edge technology to create soulful, seamless, and engaging experiences.

## 🚀 Features

- **3D Experiences**: Integrated 3D elements using Three.js and React Three Fiber.
- **Dynamic Animations**: Smooth transitions and interactive elements powered by GSAP and Motion.
- **Responsive Design**: Fully responsive UI built with Tailwind CSS.
- **Interactive UI**: Custom cursors, background layouts, and interactive carousels.
- **Modern Tech Stack**: Built with React 19 and Vite for optimal performance.

## 🛠️ Tech Stack

- **Frontend**: [React](https://reactjs.org/), [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Animations**: [GSAP](https://greensock.com/gsap/), [Motion](https://motion.dev/)
- **3D Rendering**: [Three.js](https://threejs.org/), [@react-three/fiber](https://docs.pmnd.rs/react-three-fiber), [@react-three/drei](https://github.com/pmndrs/drei)
- **UI Components**: [Radix UI](https://www.radix-ui.com/), [Lucide React](https://lucide.dev/)
- **Carousels**: [Glide.js](https://glidejs.com/), [Embla Carousel](https://www.embla-carousel.com/), [Swiper](https://swiperjs.com/)
- **Deployment**: [Vercel](https://vercel.com/)

## 📦 Getting Started

### Prerequisites

- Node.js (Latest LTS recommended)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone <repository-url>
   cd endorphind
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```

## 📂 Project Structure

- `src/components`: Reusable UI components and feature-specific components.
- `src/pages`: Main page components (Home, Project, Service, etc.).
- `src/assets`: Static assets like images and fonts.
- `src/lib`: Utility functions and shared logic.
- `public/`: Static files served directly.

## 🌐 Deployment

The project is configured for easy deployment on Vercel. Simply connect your repository to Vercel and it will automatically detect the Vite configuration.
